# Graph Algorithms: Real-World Problem Solutions

## Project Overview

This project implements four fundamental graph algorithms to solve real-world problems including social networking, navigation, emergency response, and infrastructure planning.

## Problems Solved

1. **Social Network Friend Suggestion** - BFS/DFS
2. **Google Maps Routing** - Bellman-Ford Algorithm
3. **Emergency Path Planning** - Dijkstra's Algorithm
4. **Network Cable Installation** - Minimum Spanning Tree (Prim's/Kruskal's)

## Installation & Setup

```
# Create virtual environment
python -m venv venv

# Activate virtual environment (Windows)
.\venv\Scripts\Activate.ps1

# Install dependencies
pip install -r requirements.txt
```

## Running the Code

```
jupyter notebook graph_realworld.ipynb
```
